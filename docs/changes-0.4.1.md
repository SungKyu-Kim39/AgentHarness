# Ned 0.4.1 변경 사항

사내망에서 사용자가 직접 사용하고 승인한 0.4.0 rebuild6을 정식 릴리스로 승격했습니다. 호스트, 에이전트, 편집기 패치와 번들 의존성은 rebuild6 기준이며, 제품 버전과 설치·배포 메타데이터를 0.4.1로 맞췄습니다.

0.4.0의 통합 기능과 여섯 차례 교차 검토에서 반영한 수정 사항을 포함합니다. 0.4.0 rebuild6에서 업데이트할 때는 현재 Ned와 개인 Zed를 종료한 뒤 같은 폴더에 설치합니다. 사용자 설정·대화·지식과 사용자 글로벌 스킬은 기존 Ned 데이터 경로에 유지됩니다.
