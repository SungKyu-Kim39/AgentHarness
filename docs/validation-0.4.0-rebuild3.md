# Ned 0.4.0 rebuild3 검증

Linux에서 TypeScript, 문서 일관성, 기본 스킬 무결성과 관련 회귀 테스트를 실행했습니다. 합성 모델·엔진을 사용해 REA 명시 요청 후 중지·재연결·반복 이어가기, 다른 세션 및 사용 중지 사례에서 모델 노출과 호스트 판정이 일치하는지 확인했습니다. 파일 적용 도중 발생한 사용자 편집이 롤백으로 사라지지 않는지도 확인했습니다. 기억 제외 요청과 답변이 증분 페이지 경계를 사이에 두고 저장되는 상황에서는 제외된 답변을 건너뛰고 다음 일반 턴을 수집하는지 확인했습니다.

Windows Server의 기준은 공개 0.4.0 rebuild2입니다. 설치 검증에는 잠금으로 복구가 막힌 경우 원본 백업의 SHA-256이 유지되고, 잠금 해제 후 같은 경로에서 다시 설치할 수 있는지 확인하는 시나리오를 포함합니다. 직원 PC의 실제 Windows GUI와 사내 모델·임베딩·망 차단은 별도의 수용 항목입니다.

## 설치 파일과 Windows 결과

제품 소스는 `36c5c99c30e2236ad5a35bb0f555e1fa34ade55e`입니다. Windows Server에 최종 EXE를 새로 설치해 51건 중 51건 통과, 0건 제외, 실패 0건을 확인했습니다. 0.4.0-rebuild2에서 제자리 업데이트해 사용자 스킬 원본과 참조 문서의 SHA-256이 유지됐고 제거한 등록·복구 리소스가 설치 폴더에 남지 않았습니다.

설치 EXE는 1551446671 bytes, SHA-256 `04cf4d54d48a8f0faca67e1ddcd6aee40d1b7ad70e487c5a7e7c267f36f48da4`입니다. 준비본과 추출본의 65721개 파일을 모두 대조했습니다.
