# Ned 0.4.0 rebuild2

0.4.0 제품 번호를 유지한 사전 릴리스입니다. 읽기 전용 도구의 프로젝트 Python 실행 승인·격리, 160 KB 초과 파일 복원·워커 결과 파일 전송, 다중 파일 쓰기 롤백, OpenViking 비동기 커밋 작업 확인·증분 동기화, NSIS 업그레이드 자동 복구, 설정·스킬 정책 정합성을 보완했습니다.

[변경 사항](changes-0.4.0-rebuild2.md) · [검증 기록](validation-0.4.0-rebuild2.md)
