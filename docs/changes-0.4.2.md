# Ned 0.4.2 변경 사항

- 트레이의 **사용자 MCP 관리**에서 사내 Streamable HTTP 서버를 등록합니다. 연결 확인에서 받은 도구 중 필요한 것만 선택해 저장하고 서버별로 사용 상태를 변경할 수 있습니다.
- 켜진 사용자 MCP는 Ned Agent 입력창의 `/mcp-<명령 ID>`로 표시됩니다. 선택한 요청 한 번에만 도구를 공개하며, 실행 전 서버와 보낼 인자를 다시 확인합니다. 다음 요청, 취소, 대화 종료, 토글 끄기로 권한이 해제됩니다.
- 도구 계약이 변경되면 연결 확인과 저장을 다시 요청합니다. 응답이 끊겨 실행 여부를 확인할 수 없을 때는 호출을 자동으로 반복하지 않습니다.
- 트레이 **사용 안내**를 설치와 첫 실행, 통합 사용 가이드, 사용자 스킬·MCP 등록, 버전 변경 사항으로 정리했습니다.
