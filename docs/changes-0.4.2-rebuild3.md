# Ned 0.4.2 rebuild3 변경 사항

Ned Agent 입력창에서 `/`를 입력하면 기본 명령(`/compact`), 글로벌·프로젝트 스킬, 켜진 사용자 MCP가 각각 **Commands**, **Skills**, **MCP Server Commands**로 표시됩니다. 사용자 MCP를 켜거나 끄면 열린 대화의 명령 목록에도 반영됩니다.

사용자 MCP는 이전과 같이 이번 요청에 사용할 `/mcp-…` 명령을 사용자가 선택한 뒤, 도구 실행 확인을 거쳐 사용합니다.
