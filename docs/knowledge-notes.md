# Ned Agent에서 지식 쌓기

Ned에 “이 빌드 절차를 이 프로젝트에 기억해줘” 또는 “이 커밋 규칙을 모든 내 프로젝트에 기억해줘”라고 요청합니다. 승인창에서 저장할 내용과 범위를 확인하면 로컬 OpenViking이 내용을 저장하고 설정한 사내 임베딩 서버로 색인합니다. 새 개인 저장소는 첫 승인 시 준비됩니다.

프로젝트 지식에는 설계 결정, 장애 해결 방법, 빌드 절차를 기록합니다. 개인 공통 지식에는 여러 프로젝트에서 참고할 규칙과 사용자의 작업 선호도를 기록합니다. 다른 프로젝트에서 앞서 저장한 공통 지식을 요청하면 Ned Agent가 찾아볼 수 있습니다. 프로젝트 지식은 저장한 프로젝트에서 검색합니다.

“Ned에 저장한 프로젝트 지식 목록을 보여줘”, “방금 저장한 빌드 절차를 수정해줘”, “이 지식을 삭제해줘”처럼 요청할 수 있습니다. 갱신과 삭제도 승인창에서 확인합니다. 동일한 범위와 제목은 기존 지식의 갱신으로 처리합니다. Ned는 관련 지식의 출처를 표시하며, 사용자가 별도로 요청한 원문이나 요약만 저장합니다. 기존에 가져온 OpenViking 개인 자료는 계속 읽을 수 있습니다.

OpenViking은 [모델·임베딩 설정](offline-setup.md)이 적용된 상태에서 사용합니다. 파일을 직접 색인하는 방식도 유지됩니다.
