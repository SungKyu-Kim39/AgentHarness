# 구현 현황과 남은 검증

현재 배포 기준은 Ned 0.3.7입니다. 기능 구현, 빌드·파일 검사, 실제 사용 환경 검증을 나누어 진행합니다.

1. **편집기와 에이전트:** Ned 아이콘, 전용 Zed 프로필과 ACP 연결을 구현했습니다. 고정 OpenCode 엔진의 모델 목록·대화·승인 편집과 미저장 버퍼 보호는 Linux 연동으로 확인했습니다.
2. **기존 자료와 빌드 제어:** L-Vibe 설정·기록을 보존해 복사하고 VS2017/2019를 탐색합니다. MSBuild 대상·인자를 고정하고 승인 뒤 재검사하며 Job Object로 실행을 관리합니다. 실제 Windows 빌드·취소는 별도 확인 항목입니다.
3. **배포:** Zed Windows 바이너리·원본 소스·고지, 기존 오프라인 런타임과 스킬 66개를 하나의 설치기에 넣었습니다. 0.3.7은 파일 배치를 정리하고 Windows Server에서 설치·로딩을 확인했습니다.
4. **직원 PC 검증:** 일반 사용자 설치·설정·이관·수동 저장·ACP 모델 전환·실제 MSBuild와 중지·OpenViking 등록·검색·재시작을 Windows 10·11에서 확인합니다.
5. **폐쇄망 검증:** 설치부터 종료까지 DNS·TCP와 최초 다운로드 시도를 관찰하고 실제 Qwen·BGE API, SDK가 있는 C++ 프로젝트를 검사합니다.
6. **후속 기능:** v2 반복 탐지·종료 확인·수동 답변 재출력 통합, 세션 전체 스냅샷 비교와 장기 대화 결정 보존을 구현합니다.

각 결과에는 OS·버전·해시·명령·관찰 내용을 남깁니다. 전체 Windows·사내망 검증이 끝나기 전에는 `releaseReady: false`를 유지합니다. 세부 결과는 [0.3.7 기록](validation-0.3.7.md)에 있습니다.
