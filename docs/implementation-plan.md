## 2. 설정·정책·서비스 이관

- 여러 LLM JSON을 native credential store와 공식 모델 선택 흐름에 연결한다. 임베딩은 한 개만 허용한다.
- 실제 키·엔진 자격증명을 렌더러에 전달하지 않는 transport를 구현하고 네트워크/로그를 검사한다.
- 기본 도구·MCP·수정·명령에 동일 승인 경계를 적용한다. 통제되지 않은 실행은 차단한다.
- OpenViking의 앱 동반 시작·종료와 명시적 프로젝트 파일 색인을 실제 배포본에서 확인한다.
- Serena/clangd, Graphify 로컬 AST, REA 정적 분석을 고정 번들로 연결한다. 미검증 기능은 노출하지 않는다.
- 스킬/Aegis/Conductor는 필요한 지침만 읽고 실제 도구 호출과 검증 근거를 남긴다.
- assistant 텍스트 반복 감지 → 중지 확인 → 수동 답변 재출력을 공식 세션 ID와 연결한다.

## 3. 직원 PC 수용 검증

Win10/11 x64, 일반 사용자, 외부 인터넷 차단, 사내 테스트 모델만 허용한 환경에서 설치·설정 가져오기·암호화·다중 LLM 선택·단일 임베딩·도구 승인·중지·재출력·업데이트·제거 후 데이터 보존을 검증한다. OS·빌드 해시·endpoint 종류·명령·관찰 결과를 기록한다.

번들 확보·단위 테스트·합성 서버·설치 EXE 생성은 각각 증거일 뿐, 실제 Windows 및 사내 모델 검증을 대신하지 않는다.
