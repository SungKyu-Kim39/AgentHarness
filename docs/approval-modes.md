# Ned approval options

## Current behavior in 0.3.2

프로젝트 읽기·검색은 프로젝트 접근 승인을 받은 범위에서 자동 수행한다. 파일 수정은 호스트 승인창을 거친다. 승인창의 **이번 요청의 파일 수정 자동 승인 (새 요청·중지·재시작 시 해제)**을 선택하면 같은 사용자 요청의 후속 파일 수정에 다시 묻지 않는다. 다른 요청·프로젝트·세션에 승인을 넘기지 않으며, 중지와 재실행으로 해제한다. 충돌·저장하지 않은 편집 내용·보호 경로·프로젝트 범위·스냅샷 검사는 자동 승인 여부와 함께 적용한다.

빌드, 데스크톱 동작, 지식 색인 등 별도 효과를 가진 작업은 각각 승인한다. 설정 JSON에 OpenCode 권한을 허용하는 항목을 넣어도 Ned 호스트의 승인 정책을 덮어쓰는 기능은 없다. 0.3.2에는 대화 전체에 유지되는 자동 승인이나 별도 모델이 승인 여부를 판단하는 기능이 구현되어 있지 않다.

## Proposed extension, not implemented

사용자가 선택한 대화·프로젝트 범위에서 파일 수정을 자동 승인하는 모드를 제안한다. 실행 중에 해제할 수 있고 다른 대화·프로젝트·재시작으로 승인을 넘기지 않는 구성이다. 충돌·저장하지 않은 버퍼·보호 경로 검사는 계속 적용한다. 빌드·데스크톱·자료 색인의 자동 승인은 파일 수정과 구분하여 범위를 정해야 한다. 이 절은 향후 설계 제안이며 현재 사용 가능한 메뉴가 아니다.
