# Ned permission modes (0.3.5)

대화 입력창의 **권한** 선택 메뉴 또는 Windows 알림 영역의 **Ned → 권한**에서 모드를 선택한다. 선택 즉시 적용되며 모든 Ned 대화에 공통 적용한다. `%APPDATA%\Ned\permissions.json`에 저장하므로 새 대화·프로젝트·재시작·업데이트 후에도 유지된다. 모델 JSON 교체와도 별개이다. 최초 기본값은 **승인 요청**이며 전체 권한을 선택할 때 추가 확인창을 다시 띄우지 않는다.

| 모드 | 자동 처리 | 승인을 요청하는 작업 |
|---|---|---|
| 승인 요청 | 이미 승인한 프로젝트의 읽기·검색 | 파일 수정, 빌드, 지식 전달, 데스크톱 도구 |
| 프로젝트 파일 자동 승인 | 선택한 프로젝트의 읽기·파일 수정 | 빌드, 지식 전달, 데스크톱 도구 |
| 전체 권한 | Ned가 지원하는 프로젝트 접근·파일 수정·빌드·지식 전달·앱 실행·데스크톱 관찰과 조작 | 해당 도구의 반복 승인창 없음 |

전체 권한에서도 파일 도구의 프로젝트 경계, 보호 경로, 외부 변경 충돌, 저장하지 않은 편집 내용, 실행 대상 확인, 중지와 종료 확인은 유지된다. 파일 자동 승인만 선택한 경우 데스크톱은 자동 승인되지 않는다. 전체 권한은 현재 지원하는 도구의 실행 승인을 자동으로 처리하는 기능이며 새 명령 실행기나 인터넷 연결 기능을 추가하는 설정이 아니다. 빌드와 GUI 앱은 일반 사용자 권한에서 자체 파일·네트워크 효과를 낼 수 있으며 OS 샌드박스를 의미하지 않는다. 화면·지식 내용은 설정한 사내 모델/임베딩 서버로 전달될 수 있다.

**승인 요청**을 선택하거나 알림 영역의 **모든 자동 승인 해제 · 승인 요청으로 전환**을 선택하면 되돌릴 수 있다. 권한 변경은 대기 중인 승인과 진행 중인 도구의 취소 신호에도 반영되며, 변경 전에 받은 승인을 이용해 뒤늦게 파일을 쓰지 못한다. 전달 여부가 불확실한 데스크톱 동작을 자동 재시도하지 않는다. 설정 적용 재시작 대기 중에는 전체 권한도 새 실행을 허용하지 않는다.

이는 사용자가 직접 고르는 호스트 정책이며 AI가 위험을 판단해 대신 승인하는 기능은 아니다. 제품 범위와 같은 실제 사용자 결정 질문은 그대로 남는다. 기본 스킬의 도구별 승인 안내도 이 호스트 모드에 따라 처리하며 모델이 별도로 채팅에서 같은 실행 허락을 다시 요구하지 않도록 한다. 임의 플러그인·프로젝트 설정이 이 권한 모드를 바꾸거나 승인 API를 호출할 수는 없다.

## 기존 요청·대화 단위 파일 수정 승인

아래는 **승인 요청** 모드에서 승인창을 통해 선택하는 임시 파일 수정 승인이다. 위의 영구 권한 모드와 구분한다.



프로젝트 읽기·검색은 승인한 프로젝트 범위에서 자동 수행한다. 파일 수정 승인창은 거절, 이번 수정 승인, **현재 대화·프로젝트 자동 승인**을 제공한다. 마지막 항목을 선택하면 동일한 대화·프로젝트에서는 새 사용자 메시지의 파일 수정도 다시 묻지 않는다. 이번 요청만 허용하려면 이번 수정 승인과 기존 체크박스를 사용한다.

대화·프로젝트 자동 승인은 메모리에만 보관한다. 다른 대화·프로젝트 사용, 중지, Ned 재시작, 설정 적용을 위한 재시작 요청 또는 수동 해제로 종료하며 다른 세션으로 넘기지 않는다. 알림 영역의 **권한 및 자동 승인 상태**에서 대화·프로젝트를 확인하고 **모든 자동 승인 해제 · 승인 요청으로 전환**로 즉시 해제한다. 이미 진행 중인 수정도 다음 쓰기 전 취소를 검사한다.

충돌·저장하지 않은 편집 내용·보호 경로·프로젝트 범위·스냅샷 검사는 계속 적용한다. 사용자 결정이 필요한 제품 범위 질문에 답한 것으로 간주하지 않는다. OpenCode의 `always` 권한이나 JSON에 영구 허용을 저장하지 않으며, 별도 LLM이 승인을 판단하는 기능은 아니다.

빌드, 앱 실행, 데스크톱 관찰·동작, 지식 색인은 각각 별도 승인을 받는다. 설정 JSON의 OpenCode 권한으로 Ned 호스트 정책을 덮어쓰지 않는다. 0.3.2 설치본에는 이번 요청 단위 자동 승인만 있으므로 대화·프로젝트 모드에는 0.3.3 이상이 필요하다.

Zed의 이전 기본 선택값이 권한을 다시 올리지 않도록 권한 선택 항목은 호스트 정책 버전과 함께 갱신한다. 다른 창이나 새 대화에서 오래된 전체 권한 값을 재전송하면 거절하고 최신 상태를 사용한다.
