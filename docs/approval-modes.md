# Ned 권한 설정

Ned 0.3.5부터 대화 입력창의 **권한** 메뉴와 Windows 알림 영역의 **Ned → 권한**에서 승인 방식을 선택할 수 있습니다. 최초 기본값은 **승인 요청**입니다.

선택한 모드는 모든 Ned 대화에 바로 적용됩니다. `%APPDATA%\Ned\permissions.json`에 저장하므로 프로젝트 전환, 재시작, 업데이트 후에도 유지됩니다. 모델 JSON을 교체해도 권한 설정은 그대로입니다. 전체 권한을 선택할 때 추가 확인창은 띄우지 않습니다.

0.3.7 수정 빌드 1부터 파일 변경에는 생성·수정뿐 아니라 `delete_file`을 통한 단일 텍스트 파일 삭제도 포함합니다. 삭제는 같은 권한 모드와 미저장 버퍼·외부 변경 검사를 거치며 원본을 스냅샷에 보관합니다. [삭제 범위와 복구 안내](ned-user-guide.md#file-deletion)를 확인하세요.

| 모드 | 자동으로 처리하는 작업 | 승인을 받는 작업 |
| --- | --- | --- |
| 승인 요청 | 승인한 프로젝트의 읽기·검색 | 파일 수정, Git 쓰기, 빌드·Ghidra 분석, 지식 전달, 데스크톱 도구 |
| 프로젝트 파일 자동 승인 | 선택한 프로젝트의 읽기·파일 수정 | Git 쓰기, 빌드·Ghidra 분석, 지식 전달, 데스크톱 도구 |
| 전체 권한 | 지원하는 프로젝트 접근·파일 수정·Git 쓰기·빌드·Ghidra 분석·지식 전달·데스크톱 및 명시한 외부 로컬 자료 읽기 | 해당 도구의 반복 승인창을 생략합니다. |

## 전체 권한의 적용 범위

전체 권한에서는 지원하는 도구의 실행 승인을 자동으로 처리합니다. 파일 변경 도구의 프로젝트 경계와 보호 경로, 외부 변경 충돌, 저장하지 않은 편집 내용, 실행 대상, 중지·종료 상태는 계속 확인합니다. 파일 자동 승인만 선택한 경우에는 데스크톱 작업의 승인을 별도로 받습니다.

빌드와 GUI 앱은 일반 사용자 권한으로 실행되며 자체 파일·네트워크 동작을 할 수 있습니다. 화면과 지식 내용은 작업에 따라 설정한 사내 모델·임베딩 서버로 전달될 수 있습니다.

권한은 사용자가 정한 호스트 정책으로 처리합니다. AI가 작업의 위험을 평가해 대신 승인하는 방식은 아닙니다. 기본 스킬의 승인 안내도 이 모드를 따르며, 이미 허용한 도구 실행을 채팅에서 다시 묻지 않도록 합니다. 제품 범위나 유지할 기능을 정하는 질문은 여전히 사용자 판단이 필요합니다.

## 승인 모드로 되돌리기

**승인 요청** 또는 **모든 자동 승인 해제 · 승인 요청으로 전환**을 선택하면 자동 승인을 해제합니다. 모드 변경 시 대기 중인 승인과 진행 중인 도구에 취소 신호를 보냅니다. 이전 승인으로 뒤늦게 파일을 쓰지 않도록 다음 쓰기 전에도 상태를 확인합니다.

전달 여부가 불확실한 데스크톱 동작은 자동으로 다시 실행하지 않습니다. 설정 적용을 위한 재시작이 대기 중일 때도 새 작업을 시작하지 않습니다. Zed의 다른 창이나 새 대화가 오래된 전체 권한 값을 보내면 호스트 정책 버전을 확인해 거절하고 최신 상태를 사용합니다. 프로젝트 설정이나 임의 플러그인에서 이 모드를 바꾸거나 승인 API를 호출할 수는 없습니다.

## 요청·대화 단위로 잠시 허용하기

승인 요청 모드에서도 파일 수정 승인창에서 임시 자동 승인을 선택할 수 있습니다.

- **이번 수정 승인**과 기존 체크박스를 사용하면 이번 요청의 같은 프로젝트 파일 수정을 이어서 허용합니다.
- **현재 대화·프로젝트 자동 승인**은 같은 대화의 후속 메시지에도 적용됩니다. 0.3.3부터 지원하며, 0.3.2는 요청 단위 승인만 지원합니다.

임시 승인은 메모리에 보관합니다. 대화·프로젝트 전환, 중지, 재시작, 설정 적용을 위한 재시작 요청, 수동 해제 시 종료됩니다.

이 범위에서도 충돌, 편집 버퍼, 보호 경로와 스냅샷을 검사합니다. 빌드·앱 실행·데스크톱·지식 색인은 별도로 승인하며, 임시 파일 승인을 제품 결정에 대한 답으로 사용하지 않습니다. 엔진의 `always` 권한이나 모델 JSON에 영구 허용을 저장하지 않습니다. Zed에서 직접 코드를 편집하고 저장하는 동작은 AI 승인과 별개입니다.

## 0.3.8 추가 범위

Git 스테이징·커밋과 REA Ghidra 분석은 명령 실행 정책을 따릅니다. 전체 권한에서는 지원하는 동작을 자동 승인합니다. 전체 권한에 한해 프로젝트 밖의 명시한 로컬 텍스트 파일 읽기와 폴더 목록 조회도 제공합니다. 외부 파일 생성·수정·삭제는 허용하지 않습니다. [예시와 제한](git-and-binary-analysis.md)을 참고하세요.

## Ned Agent의 터미널 명령

CMD와 PowerShell 명령은 실행 작업으로 처리합니다. 승인 요청과 프로젝트 파일 자동 승인
모드에서는 셸·명령·작업 폴더를 보여 주고 승인받습니다. 전체 권한 모드에서도 자동 승인은 프로젝트 안의 단순한 읽기 명령에 한정합니다. 쓰기·삭제·원격 명령과 영향 범위를 확인할 수 없는 스크립트는 매번 승인합니다. 명령은 Windows 사용자 권한으로 실행되며, 셸에서 바꾼 파일에는 Ned 파일
편집 도구의 스냅샷이 적용되지 않습니다. 대화에서 중지를 누르면 실행 중인 해당 대화의
셸 프로세스도 중지합니다.

프로젝트·개인 지식에 새 메모를 저장하거나 갱신·삭제할 때는 권한 모드와 관계없이 내용을 확인받습니다.
