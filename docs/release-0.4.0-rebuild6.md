# Ned 0.4.0 rebuild6

0.4.0 제품 버전을 유지한 사전 릴리스입니다. 체크포인트 복원과 제거 시 기존 파일 보존, OpenViking 응답 유실 복구, OpenAPI 요청·응답 검증, ACP 대화 정리 및 사내 PyPI 다운로드 대상 제한을 적용했습니다.

[변경 사항](changes-0.4.0-rebuild6.md) · [검증 기록](validation-0.4.0-rebuild6.md)

설치 파일 65,730개를 준비본과 대조했습니다. Windows Server에서 새 설치, 0.4.0-rebuild5 업데이트와 사용자 글로벌 스킬 보존을 확인했고 설치본 대상 검사 65건이 통과했습니다. 직원 PC의 Windows 10·11 GUI와 실제 사내 모델 검증은 남아 있어 사전 릴리스로 제공합니다.
