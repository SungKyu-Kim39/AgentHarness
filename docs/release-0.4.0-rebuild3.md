# Ned 0.4.0 rebuild3

0.4.0 제품 번호를 유지한 사전 릴리스입니다. 중단된 REA 분석 이어가기, 사용자 편집을 보존하는 파일 롤백, 중단된 업데이트의 백업 복구를 보완했습니다.
