# Ned 0.3.10 변경 사항

## Windows 터미널

터미널 패널의 **+ (New…)** 메뉴에서 **PowerShell**과 **CMD**를 골라 프로젝트 폴더에
새 탭을 엽니다. 이전 터미널 설정과 기존 탭은 보존합니다.

Ned Agent는 각 쉘에서 명령을 실행하고 출력과 종료 코드를 확인할 수 있습니다.
CMD 명령에는 배치 문법을 사용합니다. 명령은 프로젝트에서 시작하며 Windows 사용자
권한으로 실행합니다. Ned의 [권한 정책](approval-modes.md#ned-agent의-터미널-명령)이
승인 여부를 정합니다. 실행 중인 명령은 같은 대화에서 중지할 수 있습니다.

## OpenViking Studio와 스킬

Studio의 작업 화면이 렌더링됐는지 확인합니다. 인증, 브라우저 저장소, 리소스 및 렌더러 오류는
진단 코드로 표시합니다. **다시 불러오기**는 Studio 연결과 화면을 다시 초기화합니다.
[Studio 안내](openviking-studio.md)

기본 스킬 74종은 설치 파일에서 사용합니다. 최초 설치·업데이트·재실행 단계에서 OpenViking에
스킬을 등록하거나 재확인하지 않습니다. 프로젝트 지식 색인과 검색, 기존 개인 지식 검색과
개인 Zed Agent 대화 가져오기는 계속 사용할 수 있습니다. Ned의 새 개인 공통 지식
`.ovpack` 가져오기는 제거했습니다. 업데이트에서 기존 지식이나 기록을 삭제하지 않습니다.

## 사용자 글로벌 스킬

`%APPDATA%\Ned\skills\<스킬-ID>\SKILL.md`에 저장한 지침을 모든 Ned 프로젝트에서
사용할 수 있습니다. Ned를 재시작하면 등록되고, 프로그램을 업데이트해도 파일은 유지됩니다.
[등록 방법과 예시](extension-guide.md#사용자-글로벌-스킬-등록)

## 트레이 메뉴

기본 터미널, 권한 및 자동 승인 상태, OpenViking 기본 스킬 등록 상태와 재확인, 개인 공통
지식 가져오기와 가져오기 상태를 제거했습니다. 권한 변경과 자동 승인 해제는 트레이에서
계속 사용할 수 있습니다. [설치 및 사용 안내](offline-setup.md)
