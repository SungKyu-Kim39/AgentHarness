# Ned 0.4.2

기존 사내 MCP를 Ned 트레이에서 등록하고 에이전트 입력창의 `/mcp-<명령 ID>`로 선택할 수 있습니다. 등록한 서버의 도구는 명시적으로 선택한 요청에서 사용할 수 있으며, 도구 호출 전 전송할 정보를 확인합니다. 트레이의 사용 안내도 네 항목으로 정리했습니다.

[변경 사항](https://github.com/SungKyu-Kim39/AgentHarness/blob/v0.4.2/docs/changes-0.4.2.md) · [사용자 스킬·MCP 등록](https://github.com/SungKyu-Kim39/AgentHarness/blob/v0.4.2/docs/extension-guide.md)

설치 파일 65,736개를 준비본과 대조했습니다. Windows Server에서 새 설치, 0.4.1 업데이트와 사용자 글로벌 스킬 보존을 확인했고 설치본 대상 검사 69건이 통과했습니다. 직원 PC의 Windows 10·11 GUI와 실제 사내 모델 검증은 남아 있어 사전 릴리스로 제공합니다.
