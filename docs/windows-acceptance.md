# Windows·사내망 배포 확인 목록

이 목록은 직원 PC에서 확인할 절차입니다. 체크하지 않은 항목은 미확인으로 남깁니다. Linux·합성 모델 검사와 EXE 생성, Windows Server 결과는 [0.3.7 검증 기록](validation-0.3.7.md)에 따로 있습니다.

## 실행 환경 기록

Win10·Win11 x64 일반 사용자 VM마다 OS edition·build, 계정 종류, 앱 버전, 설치 EXE·`app.asar` SHA-256과 vendor-lock 해시를 기록합니다. 모델은 합성인지 실제 사내 서버인지 구분하고 실행 명령과 DNS·TCP 관찰을 남깁니다. 실제 API 키는 기록에 넣지 않습니다.

## 설치·설정·종료

- [ ] EXE 옆 배포 JSON을 두고 다른 CWD에서 일반 사용자로 설치합니다. 관리자 권한·UAC 상승 요청이 없는지 확인합니다.
- [ ] 설치 폴더와 `%APPDATA%\Ned` 데이터가 분리되고 ACL·배포 폴더 접근 권한이 맞는지 확인합니다.
- [ ] 기본 경로와 다른 드라이브, 아직 없는 상위 폴더에 설치하고 업데이트가 등록 경로를 재사용하는지 확인합니다.
- [ ] 준비 설정이 설치기 `$EXEDIR`에서 복사되고 CWD나 설치 후 EXE 옆 파일을 잘못 읽지 않는지 확인합니다.
- [ ] 첫 실행에서 JSON 검증·safeStorage/DPAPI 암호화·준비 평문 삭제를 확인하고 배포 원본이 남는지 확인합니다.
- [ ] 잘못된 JSON·필드·URL을 가져오면 원인을 알리고 기존 설정을 보존하는지 확인합니다.
- [ ] 사용자가 선택한 파일로만 설정을 교체하며 모델 목록을 임의 조회하지 않는지 확인합니다.
- [ ] 설정 적용 시 저장 확인·정상 종료·서비스 종료·자동 재시작과 취소 동작을 확인합니다.
- [ ] 업데이트·제거·재설치 후 설정·대화·지식·편집기 환경이 유지되는지 확인합니다.
- [ ] 손상 설정·다른 계정의 복호화 실패 시 덮어쓰기나 평문 대체가 없는지 확인합니다.
- [ ] 손상·미지원 기록 버전의 원본을 보존하고 신규 저장을 막는지 확인합니다. 향후 DB 이관은 백업·복구도 검사합니다.

## 실행과 승인

- [ ] 렌더러가 Node·require·키·모델 API에 직접 접근하지 않고 잘못된 출처·프레임·스키마 IPC를 거절하는지 확인합니다.
- [ ] 외부 탐색·팝업·webview·권한 요청을 차단하는지 확인합니다.
- [ ] 프로젝트·전역 opencode.json·플러그인·개인 홈·Zed 설정을 상속해 실행하지 않는지 확인합니다.
- [ ] 허용한 도구만 노출하고 미등록 MCP·REPL·일반 명령·웹 도구를 거절하는지 확인합니다.
- [ ] 범위 밖 경로, Windows ADS·장치·junction·symlink·UNC·경로 교체 경쟁을 검사합니다.
- [ ] 승인 전 원본을 바꾸지 않고 대상과 내용을 고정하며 외부 수정·삭제·재생성 시 충돌을 확인하는지 검사합니다.
- [ ] Git 없는 프로젝트에서도 변경 비교와 실제 저장 재읽기가 맞는지 확인합니다.
- [ ] 임시 요청·대화 승인은 정해진 전환·중지·재시작 조건에서 해제되고 엔진 `always`에 남지 않는지 확인합니다.
- [ ] 지속 권한 ask·edits·full은 저장·업데이트 후 유지되고 오래된 선택이 해제한 권한을 다시 올리지 않는지 확인합니다.

## 네트워크와 비밀 정보

- [ ] 외부 인터넷을 막고 시험 모델만 허용한 새 VM에서 설치부터 재시작까지 DNS·TCP를 수집합니다.
- [ ] 업데이트·models.dev·외부 인증·텔레메트리·검색/fetch/공유·원격 스킬·첫 LSP·토크나이저 다운로드 시도를 확인합니다.
- [ ] 사내 Qwen의 실제 ID·baseUrl·tool call·stream·reasoning·한도를 검사합니다. 32768/4096 기본값을 서버 사양으로 간주하지 않습니다.
- [ ] UI·로그·기록·내보내기·엔진 진단·DB·crash dump에 테스트 키가 새지 않는지 확인합니다.
- [ ] 모델 게이트웨이의 리다이렉트·다른 모델·모델 목록·임의 경로 거절을 검사합니다.

## 작업 중지와 후속 기능

- [ ] assistant 문장·연속 구절 반복을 스트리밍 중 감지하고 reasoning·사용자·도구·코드 반복과 구분합니다.
- [ ] 중지 요청·확인·미확인 상태를 구분하고 abort·idle·실행 도구 없음 확인 전 재출력과 새 실행을 막습니다.
- [ ] 자동 재출력 없이 수동 요청만 처리하고 tools 없음·tool_choice none, 반환 tool/function call 실행 거절을 검사합니다.
- [ ] 재출력은 원래 세션에 별도 답변으로 저장하고 재반복·중지 뒤 상태를 확인합니다.
- [ ] 고정 실행 파일·인자·CWD·환경·대상과 승인을 확인하고 Job Object의 자식 종료를 검사합니다. 현재 지원 MSBuild와 후속 일반 명령을 구분합니다.

반복 탐지·재출력의 v2 통합과 세션 전체 비교는 남은 구현 항목이므로 구현과 검증을 마친 뒤 체크합니다.

## 분석·지식·대규모 작업

- [ ] Serena read-only MCP·고정 clangd·DLL·`ls_path`와 프로젝트 설정 우회 거절을 검사합니다.
- [ ] 실제 C++ 정의·참조·호출 영향, 실패 시 텍스트 검색 대체와 SDK·compile_commands 제한 표시를 확인합니다.
- [ ] 관련 Conductor 트랙·spec·plan을 읽고 쓰기 정책에 따라 갱신하는지 확인합니다.
- [ ] 큰 작업에서 Aegis 조사·계획·변경·검증을 수행하고 작은 질문에 불필요한 문서나 모든 스킬을 강제하지 않는지 확인합니다.
- [ ] VxWorks 유지 여부 같은 미결 결정에 의존한 수정은 기다리고 독립 조사는 이어가는지 확인합니다.
- [ ] 세션 전체 스냅샷, 장기 문맥 보존, DB 마이그레이션과 실행 예산을 구현·검증합니다.
- [ ] GUI 앱 실행·관찰·실제 동작·결과와 취소를 Windows UIA에서 확인합니다.

## 기본 스킬과 OpenViking

- [ ] TGZ 설치·모델 설정·첫 실행 뒤 알림 영역에서 해당 버전의 전체 기본 스킬과 참조·라이선스를 확인합니다. 0.2.1은 34/34, 0.3.7은 66개입니다.
- [ ] 재실행 때 같은 스킬로 추가 모델·임베딩 요청이 발생하지 않는지 확인합니다.
- [ ] 등록 중 종료하면 HTTP·서비스·자식이 끝나고 재실행 때 미완료 항목만 재확인하는지 검사합니다.
- [ ] 업데이트에서 편집한 사본·사용자 스킬·손상 기록을 자동 덮어쓰지 않는지 확인합니다.
- [ ] 임베딩 미설정·서비스 오류를 완료로 표시하지 않고, 등록 실패와 로컬 스킬 읽기를 분리하는지 확인합니다.
- [ ] 등록 요청에 기본 패키지만 포함하고 사용자 대화·프로젝트·키를 보내지 않는지 DNS·TCP와 함께 확인합니다.
