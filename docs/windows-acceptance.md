# Windows 출시 수용 검증

이 문서는 검증 절차다. 체크하지 않은 항목을 통과로 간주하지 않는다. 설치 EXE나 Linux/합성 모델 결과만으로 1.0 출시를 승인하지 않는다.

## 실행 환경 기록

각 Win10/Win11 x64 일반 사용자 VM에서 OS edition/build·계정 종류·앱 버전·설치 EXE 및 app.asar SHA-256·vendor-lock 해시·모델 endpoint 종류(합성/실제 사내)·실행 명령·DNS/TCP 관찰을 기록한다. 실제 API Key는 증거·로그에 넣지 않는다.

## 설치·설정·수명

- [ ] EXE 옆 배포 JSON, 서로 다른 CWD에서 일반 사용자 설치. 관리자 권한·UAC 상승 요청 없음.
- [ ] 기본 설치 경로와 `%APPDATA%\Ned` 데이터 분리, 두 경로의 ACL 및 설치 원본 배포 폴더 접근권한 확인.
- [ ] 준비 파일이 설치기 `$EXEDIR`에서 복사됨. 설치된 앱 EXE 옆·CWD 설정을 읽지 않음.
- [ ] 정상 JSON 첫 실행 → safeStorage/DPAPI 암호화 → 준비 평문 삭제. 원래 배포 파일 유지.
- [ ] 잘못된 JSON·누락 필드·잘못된 URL → 구체적 필드 오류·가져오기 제공, 기존 설정 보존.
- [ ] 설정 교체 버튼에서 파일을 선택한 경우만 교체. 자동 모델 목록 조회 없음.
- [ ] 업데이트·제거·재설치 후 설정·대화·재출력 보존.
- [ ] 손상된 설정·다른 Windows 사용자의 DPAPI 복호화 실패 → 자동 덮어쓰기·평문 대체 없음.
- [ ] 손상/미지원 기록 버전은 원본 유지·신규 저장 차단. 향후 마이그레이션은 사전 백업·실패 복구 검증.

## 실행 경계

- [ ] Node·require·API 키·직접 모델 연결이 렌더러에 없음. 출처/프레임/스키마가 다른 IPC 차단.
- [ ] 외부 탐색·팝업·webview·권한 요청 차단.
- [ ] 프로젝트/전역 opencode.json·플러그인·개인 홈·Zed 설정을 읽거나 실행하지 않음.
- [ ] 실제 노출 도구 목록은 허용 목록과 일치. 미등록 MCP·REPL·명령·웹 도구 차단.
- [ ] 범위 밖·Windows ADS/장치 경로·junction/symlink·UNC·경로 변조 차단. 동시 경로 교체 경쟁도 검증.
- [ ] 승인 전 원본 무변경. 승인 대상·내용 고정. 외부 수정/삭제/재생성 시 충돌과 새 승인 요구.
- [ ] Git 없는 프로젝트의 변경 비교·실제 저장 재읽기 일치.
- [ ] 자동 승인이 재시작·다른 세션·프로젝트 전환에서 사라짐. always 승인 저장 없음.

## 폐쇄망·비밀

- [ ] 인터넷 차단·시험 모델 endpoint만 허용한 새 VM에서 설치부터 재시작까지 DNS/TCP 수집.
- [ ] 업데이트·models.dev·인증·텔레메트리·검색/fetch/공유·원격 스킬·최초 LSP/토크나이저 다운로드 시도 없음.
- [ ] 실제 사내 Qwen의 정확한 ID·baseUrl·tool call·stream·reasoning·한도를 검증. 32768/4096을 확인된 서버 사양으로 간주하지 않음.
- [ ] 앱 UI·로그·기록·내보내기 및 엔진 자체 진단·DB·crash dump에서 테스트 키 누출 검사.
- [ ] 모델 게이트웨이가 리다이렉트·다른 모델·모델 목록·임의 경로를 거부함.

## 작업·중지·재출력

- [ ] assistant 문장 반복·연속 구절 반복이 스트리밍 중 감지됨. reasoning/사용자/도구/코드만 반복되면 해당 감지로 중지되지 않음.
- [ ] 중지 요청·확인·미확인 표시 구분. abort·idle·실행 도구 없음 확인 전 재출력과 신규 실행 차단.
- [ ] 자동 재출력 없음. 수동 재출력의 요청에 tools 없음·tool_choice none. 반환된 tool/function call 실행 거부.
- [ ] 정상 재출력은 원래 호스트 세션의 별도 답변으로 저장. 재반복·중지 후 상태 확인.
- [ ] 1.0 명령 기능: portable 실행 파일·인자·CWD·환경·대상 고정 및 승인. Job Object로 모든 자식 종료 확인. 현재 후보는 명령 비활성화.
