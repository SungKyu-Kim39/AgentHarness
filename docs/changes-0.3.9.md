# Ned 0.3.9 변경 사항

0.3.9 구현 후보입니다. 설치 파일과 Windows GUI 수용을 완료한 배포본은 아직 아닙니다.

## 기본 Zed Agent 오류

0.3.8 rebuild1이 생성한 Write·Ask·Minimal 프로필에 Zed 1.28.1의 필수 `name`이
빠져 설정 읽기가 실패했습니다. 프로필 이름과 호환 모델의 필수 capability를 명시하고,
저장 전 스키마 검사를 추가했습니다. 업데이트 시 기존 JSONC 주석·글꼴·패널·기본 선택을 유지합니다.

`Permission Denied / Ned offline editor`는 Ned의 편집기 프록시가 거부할 때 나오는
응답입니다. 기존 구현은 절대 URL 형식만 받았습니다. 0.3.9는 자체 모델 경로의
일반 HTTP 요청과 프록시 형식을 모두 처리하고, Zed 모델 설정을 같은 진입점에 연결합니다.
인증 실패, 다른 경로·포트·외부 주소는 계속 차단합니다. 고객 Windows PC의 실제 요청
형식은 아직 확보하지 못했으며, 실제 사내 모델의 첫 응답 수용은 별도 확인해야 합니다.

## 스킬 준비와 업데이트

EGM 7종을 더해 총 74종입니다. 빌드 시 OpenViking 0.5.5용 스킬·출처·요약 파일을
`vendor/skill-seed`에 준비해 설치 자료에 포함합니다. 실행 시 OpenViking이 정지한 동안
로컬 자료를 검증하고 필요한 항목만 설치합니다. 모델로 74개 스킬을 다시 요약·등록하지 않습니다.

이전 등록 개수, 이번 확인 개수, 재사용·신규·갱신을 구분합니다. 이전 버전의 정상 자료는
내용을 확인해 이어받습니다. 원본이 수정되었거나 소유권이 불명확하면 충돌로 표시하고
보존합니다. 기본 자료 갱신 전에는 `openviking/skill-backups`에 원본을 남기고,
교체 중 종료되면 기록된 원본을 복구한 뒤 재확인합니다. 이 방식은 등록 조회 시 발생하던
HTTP 409와 SDK가 만든 요약의 revision 변경 때문에 생기던 오판을 시작 경로에서 제거합니다.

로컬 스킬 준비와 의미 검색 색인은 다릅니다. 사전 준비 자료에는 모델별 벡터가 없으며
`indexStatus: not-indexed`로 표시합니다. 이전 등록 기록이 있으면 기존 색인을 지우지 않고
`unverified`로 구분하며 새 로컬 검사만으로 색인 완료를 단정하지 않습니다. Ned의 `read_skill`은 로컬 원본을 사용합니다.
프로젝트·개인 지식의 벡터는 각자의 실제 색인 상태를 따릅니다. OpenViking SDK가 첫 인증 시
만드는 기본 계정·사용자 폴더의 초기 임베딩 작업은 별개이며, 이를 스킬 재등록으로 집계하지 않습니다.

## 실행 속도와 표시

지식 서비스 준비를 백그라운드로 옮겨 편집기·Ned Agent가 이를 기다리지 않게 했습니다.
지식 서비스가 실패해도 로컬 스킬과 모델 대화는 사용할 수 있습니다. 지식 기능은 서비스가
준비된 뒤 사용할 수 있으며 트레이에서 현재 단계와 파일 검사 진행을 확인합니다.

시작 창에는 설정 이관, 모델 중계, 스킬 문서 검사 개수, 편집기 설정, 엔진, 편집기 실행을
표시하고 전체·현재 단계 경과 시간을 갱신합니다. `startup-timing.json`은 단계별 경과 시간과
호스트 CPU 시간을 기록합니다. 편집기 프로세스 생성 시점이며 첫 화면 표시 시간은 아닙니다.

파일 검증은 최대 4개씩 병행합니다. 해시 검사 자체를 생략하지 않습니다. 모든 CPU 코어에서
해시가 실행된다는 뜻은 아니며, 설치 압축 해제·디스크·백신·Python 시작 비용도 별개입니다.
실제 Win10/11에서 같은 PC·캐시 조건으로 설치/첫 실행/재실행을 비교하기 전에는 개선율을
제시하지 않습니다. LLM 생성 대기에는 새 시간 제한을 추가하지 않았습니다.

## Studio·터미널·대화

Studio는 실제 앱 DOM 표시를 확인합니다. 빈 화면이 지속되면 진단 코드와 다시 불러오기
버튼을 표시하고, HTTP 인증·자료·CSP·렌더러 종료를 비밀 없는 코드로 기록합니다.
고정 0.5.5 번들의 UUID 호환 스크립트는 정확한 CSP 해시로 허용합니다. 임의 스크립트나
외부 접속을 열지 않습니다. [Studio 안내](openviking-studio.md)를 참고하세요.

트레이의 기본 터미널 메뉴에서 PowerShell/CMD를 고르면 이후 새 터미널과 재시작에
적용됩니다. 이미 열린 터미널은 유지됩니다. 편집기의 작업 선택기에는 `Ned: CMD`,
`Ned: PowerShell`이 있으며 각각 새 통합 터미널을 프로젝트 루트에서 엽니다.
프로젝트가 없는 창에서는 먼저 프로젝트를 선택하세요.

[기존 개인 Zed Agent 대화 가져오기](zed-history-import.md)와
[EGM 사용](egm.md)을 제공합니다. 검증 범위와 배포 전 확인 사항은
[0.3.9 검증 기록](validation-0.3.9.md)에 기록합니다.
