# Ned 0.4.2 rebuild2 변경 사항

사용자 MCP 관리에서 `https://127.0.0.1:18081/mcp` 같은 로컬 주소를 연결 확인할 수 있습니다. `localhost`와 `[::1]`도 지원합니다. 사용자가 등록한 주소로 연결하며 Ned 내부 서비스 포트와 외부 공인 주소는 차단합니다.

등록 단계에서 이름, 명령 ID, URL 형식, HTTPS 인증서 신뢰 또는 주소 불일치 오류를 구분해 표시합니다.
