# Ned 0.4.1

사내망에서 사용자가 직접 사용하고 승인한 0.4.0 rebuild6을 바탕으로 만든 Windows x64 정식 릴리스입니다. 여섯 차례 교차 검토에서 적용한 수정 사항을 포함하며 제품 버전을 0.4.1로 맞췄습니다.

반입용 TGZ는 새 폴더에 풀어 함께 제공되는 EXE를 실행합니다. 업데이트하려면 Ned와 개인 Zed를 먼저 종료한 뒤 기존 Ned 설치 폴더를 선택합니다.
