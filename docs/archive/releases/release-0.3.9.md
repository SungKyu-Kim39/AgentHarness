# Ned 0.3.9

스킬 사전 준비·변경분 적용과 지식 서비스의 백그라운드 시작, 상세 실행 단계, Studio 오류 복구, CMD/PowerShell, 기존 개인 Zed 대화 가져오기와 EGM 7종을 제공합니다. 기본 스킬은 74종입니다. 기본 Zed Agent의 필수 프로필 이름과 모델 통신 프록시 호환성과 Git 패널의 Trust Directory도 수정했습니다.

설치 EXE의 전체 61,386개 파일을 준비본과 대조했습니다. Windows Server 설치 후 52건 중 52건 통과·0건 제외·실패 0건입니다. 합성 모델·설치된 런타임을 사용했으며 직원 Win10/11 GUI·실제 사내 모델 수용과는 구분해 사전 릴리스로 제공합니다.
