# Ned 0.3.9 구현 범위

사용자가 승인한 범위는 기본 스킬 등록 복구·사전 준비·변경분 적용, EGM 통합,
시작 성능과 상세 단계, Studio 흰 화면 진단·복구, PowerShell/CMD 선택,
기존 개인 Zed Agent 대화 가져오기, Zed 설정의 missing field name과 첫 메시지의 Ned offline editor 오류 수정입니다.

## 데이터와 실행 경계

- 기존 대화·암호화 설정·지식·수정된 스킬·편집기 JSONC를 보존합니다.
- 개인 Zed 설정은 복제하지 않습니다. 사용자가 요청한 대화 DB만 읽기 전용으로 열어
  Ned DB와 중복 없이 병합하고, 가져오기 전 Ned DB의 일관된 백업을 남깁니다.
- EGM은 고정된 원본 전체 문서와 Ned 어댑터를 사용합니다. Goldfish는 새로운 읽기 전용
  하위 세션에서 실행하며 개인 기억·부모 대화를 자동 주입하지 않습니다.
- 기본 스킬은 설치된 로컬 카탈로그로 즉시 사용합니다. 지식 서비스 실패와 색인 대기는
  대화 시작을 막지 않습니다. 검색 색인 준비 상태는 로컬 스킬 준비와 구분합니다.
- 서비스 준비와 사용자 생성 요청의 대기 정책은 별개입니다. 사내 모델 생성에 새 기본
  시간 제한을 추가하지 않습니다.

## 구현과 확인 순서

1. 스킬 등록·이름 조회 충돌·중단 후 기록 복구를 재현하고 기존 수정본을 보호합니다.
2. 준비된 스킬 묶음, 변경분 확인, 지식 서비스의 백그라운드 시작을 연결합니다.
3. 시작 단계·경과 시간·파일 검사 진행률과 제한된 병렬 검증을 연결합니다.
4. Studio의 실제 화면 준비 확인, 비밀 없는 오류 분류와 재시도 화면을 추가합니다.
5. CMD와 PowerShell 선택, 기본값 유지, 프로젝트 작업 폴더를 연결합니다.
6. Zed 대화의 읽기 전용 원본·트랜잭션 병합·중복·호환성·백업을 검사합니다.
7. EGM 자료·호스트 소유 Goldfish 권한·결과 전달·오프라인 배포를 연결합니다.
8. 대상 검사, 타입·스킬·호스트/ACP 빌드와 변경 후 리뷰를 수행합니다.

Linux fixture, 실제 번들 SDK, 합성 모델, Windows 설치/GUI, 실제 사내 모델 검증을
구별합니다. 실행하지 못한 검사를 통과로 표시하지 않으며 기존 배포물은 덮어쓰지 않습니다.
