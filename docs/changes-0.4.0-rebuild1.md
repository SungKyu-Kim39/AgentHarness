# Ned 0.4.0 rebuild1 변경 사항

제품 버전은 0.4.0입니다. 이번 수정 빌드는 0.4.0을 기준으로 공개 제품 코드, 호스트 도구의 호출 경로, 자동 기억과 설치 검증을 교차 검토한 결과를 반영합니다.

- 자동 스킬과 OpenViking 자동 회상은 OpenCode가 전달한 세션 ID와 Ned가 승인한 프로젝트에 연결합니다. “기억에서 빼줘”를 인식하고 세션 제외 상태를 모델 호출 전에 저장합니다.
- 앱 관리 폴더·사용자 보호 폴더와 이를 포함하는 상위 폴더를 프로젝트로 승인하지 않습니다. 기존 승인 기록도 다시 검사합니다.
- 프리뷰·Mock은 대화 중지와 호스트 종료에 연결합니다. 주 Agent의 중지 요청과 하위 작업 종료 확인은 병행합니다. Studio 탐색이나 DOM 검사 응답이 멈춰도 제한 시간이 동작합니다.
- 사내 PyPI 설치는 기본적으로 꺼져 있습니다. 중앙 설정에서 승인된 단일 HTTPS 미러와 `python.allowPackageInstall: true`를 명시한 경우에만 전체 권한 모드에서도 별도 승인을 받아 설치합니다. 고정 버전 wheel만 받으므로 의존성도 고정 버전으로 목록에 적어야 합니다. 시스템 pip 설정, 추가 인덱스, TLS 예외는 설치에 사용하지 않습니다. 미러의 파일 호스트와 네트워크 출구는 사내 정책으로 제한합니다.
- Python 패키지 문서 조회는 메타데이터, Python 소스, 타입 스텁의 정적 분석을 사용합니다. 네이티브 모듈 내부에만 있는 서명은 조회 범위에서 제외됩니다.
- Worktree에서 변경한 파일을 반영할 때 기준 커밋과 본 프로젝트 파일을 비교합니다. 본 프로젝트가 바뀌었으면 덮어쓰기 전에 중단합니다. 문서와 다이어그램 생성 도구는 사용하지 않는 출력 경로를 요구하고 입력 양식과 기존 파일을 보존합니다.
- API 계약 검증은 승인된 출처와 경로 안에서만 요청을 보내며, Ned 내부 서비스와 다른 대화의 Mock을 거부합니다. 해당 대화의 Mock을 벗어나는 요청과 변경 메서드는 별도 승인을 받습니다. Schemathesis 실행은 실제 요청 상한을 강제할 수 있을 때까지 보류합니다.

- 하위 Agent 상태는 실제 디스크에 저장하는 JSON 크기로 검사하고, 한도에 가까워지면 종료된 오래된 기록을 정리합니다. 이전 빌드에서 저장한 4 MiB 초과 기록도 복구할 수 있습니다.
- 새 Workspace Tools는 Windows에서 처음 사용할 때 릴리스의 고정 파일 목록과 해시를 검사합니다.

## 다음 교차 검토에서 확인할 항목

- OpenViking 비동기 기억 추출의 작업 상태 확인과 복구, 장시간 대화의 증분 동기화.
- 체크포인트·Worktree·AST 다중 파일 쓰기의 중간 실패 복구와 설치기의 중단 후 이전 배포본 복구.
- 실제 Windows 10·11에서 프리뷰, 문서와 Mermaid, 사내 PyPI 파일 호스트 및 사내망 차단의 수용 확인.
