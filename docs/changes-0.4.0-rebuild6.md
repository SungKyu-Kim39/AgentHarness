# Ned 0.4.0 rebuild6 변경 사항

- 체크포인트 생성 시 파일 목록의 누락 여부를 기록합니다. 생성·복원 범위와 당시 파일 존재 여부를 확인할 수 있어야 추가 파일을 삭제합니다. 기존 구버전 체크포인트는 확인된 파일 내용 복원에 사용할 수 있습니다.
- Shadow Git 체크포인트는 입력 파일의 CRLF·LF를 유지하고 `.gitignore`를 적용합니다. 생성 당시 제외해 둔 기존 파일은 나중에 무시 규칙이 바뀌어도 자동 삭제하지 않습니다.
- 제거기는 Ned가 소유한 파일과 폴더를 제거합니다. 설치 폴더 최상위에 추가한 사용자 파일, 이전 업데이트에서 미복구된 백업, 사용자 앱 데이터는 유지합니다.
- OpenViking이 쓰기를 처리했는데 응답이 끊기면 메시지 식별자 또는 아카이브 상태로 확인하고 유효한 기록을 다시 보내지 않습니다. 같은 서비스 프로세스에서 결과를 확인할 수 없는 작업은 보류하며, 재시작 후 저장 상태를 확인합니다.
- OpenAPI Mock은 JSON 요청 본문을 검증합니다. 응답의 배열 항목을 제한 범위까지 검사하고, 지원하지 않는 스키마 조건이나 검사 상한은 미완료로 표시합니다.
- Zed ACP에서 대화를 닫거나 삭제하면 Ned도 대화에 연결한 프리뷰·Mock·REA 분석 등 소유 작업을 정리합니다. REA 도구 접근은 사용자가 선택한 대화 모드를 따릅니다.
- 사내 PyPI 다운로드는 승인한 HTTPS 미러 출처와 중앙 설정에 명시한 별도 wheel 서버만 사용합니다. 리다이렉트도 같은 목적지 제한을 적용합니다.
