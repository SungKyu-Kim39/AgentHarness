Ned configuration automatic restart fix 1

Target: original Ned 0.3.1 or Ned 0.3.1 with startup fix 1.
Quit Ned and all Zed instances, unpack in a new folder and run APPLY_FIX.cmd.
Expect applied/already-applied and EXIT_CODE=0; then start Ned.
Use the tray menu to import JSON. Valid configuration is encrypted before a
normal editor-close request. Complete Zed save prompts; after confirmed editor
and service shutdown Ned relaunches automatically with the new configuration.
Save cancellation leaves restart pending; cancel that pending restart in the
tray if desired. The saved configuration stays available for next startup.
Invalid imports and unconfirmed shutdown never trigger a replacement process.

Also fixes Windows ACP lifetime: Zed launches the bundled Python console supervisor, which waits for the Electron Node agent and preserves its raw stdio. No extra runtime download.

The patch is cumulative with startup fix 1. Existing settings, keys, knowledge,
history and projects are not modified by the patch. ROLLBACK_FIX.cmd restores
the exact host archive that this patch backed up. The Control Panel version
remains 0.3.1; the refreshed host menu identifies version 0.3.2.
Actual Windows automatic restart/save-prompt behavior requires deployment verification.
