# 사내 배포 Ned 0.3.7에서 0.3.10으로 업데이트

0.3.7 최초 배포본에서 0.3.10으로 바로 올릴 때 적용되는 변경입니다. 중간에 나온 0.3.7 수정
빌드 1, 0.3.8, 0.3.8 수정 빌드 1과 0.3.9의 제품 변경도 포함합니다.

| 처음 반영된 버전 | 기능과 수정 |
| --- | --- |
| 0.3.7 수정 빌드 1 | OpenViking 0.5.4 → 0.5.5, LiteLLM 1.103.10. 기본 계정·스킬 이름을 Ned로 이관하고 이전 자료를 백업합니다. 프로젝트 텍스트 파일을 승인과 복구 스냅샷을 거쳐 삭제하는 기능과 상세 사용 안내서를 추가했습니다. |
| 0.3.8 | 저장된 대화의 요약 출력 한도 오류를 처리합니다. 자동 스킬 지침을 기존 system 메시지에 합쳐 모델 호환성을 높이고 HTTP 거부 진단에는 고정 코드만 남깁니다. |
| 0.3.8 | OpenViking Studio를 로컬 전용 창으로 제공하고 실패한 개인 OVPack 가져오기를 원본을 보존한 채 재시도할 수 있습니다. 새 스킬과 MCP를 추가·배포하는 절차를 문서화했습니다. |
| 0.3.8 | 지정한 프로젝트 파일의 Git 스테이징·로컬 커밋, 전체 권한 모드의 명시적 외부 로컬 텍스트 읽기, REA의 Ghidra 기반 정적 분석을 제공합니다. Ghidra 12.1.4와 JDK 21을 함께 반입합니다. |
| 0.3.8 | 프로젝트별 Conda 환경을 선택하고 기억합니다. 해당 환경에서 Python 실행·컴파일 검사·pytest·wheel·PyInstaller를 지원합니다. 공통 프로세스 감독기가 정상·실패 종료 코드를 전달하고 취소를 처리하도록 수정했습니다. |
| 0.3.8 수정 빌드 1 | 기본 Zed Agent와 Ned Agent를 선택할 수 있습니다. 기본 Zed Agent는 중앙 JSON의 사내 모델 연결과 Zed 자체 도구·승인을 사용합니다. 고정 Zed 1.28.1 소스로 Ned 메뉴와 About 화면을 빌드합니다. |
| 0.3.8 수정 빌드 1 | Ned Agent의 읽기 전용 조사와 지정 파일 구현 하위 Agent를 추가했습니다. 전역 동시 두 개를 운영하며 늦게 완료한 통합 답변도 ACP 편집기 대화에 전달합니다. |
| 0.3.8 수정 빌드 1 | Astryx 오프라인 UI 제작 스킬과 Windows React 시작 프로젝트를 포함해 기본 스킬을 66종에서 67종으로 늘렸습니다. |
| 0.3.9 | 기본 스킬을 미리 준비하고 변경분만 적용합니다. 사용자 수정본과 추가 파일을 보존하고, 이전 등록·이번 확인·재사용·신규·갱신·충돌을 구분합니다. 기존 HTTP 409 조회 충돌은 시작 등록 경로에서 제거했습니다. |
| 0.3.9 | 지식 서비스를 백그라운드에서 준비해 대화가 스킬 등록 완료를 기다리지 않습니다. 시작 창에 현재 단계·경과 시간·검사 개수를 표시합니다. |
| 0.3.9 | Studio의 실제 화면 표시를 확인하고 빈 화면에 진단 코드와 다시 불러오기를 표시합니다. 편집기 터미널은 PowerShell·CMD를 선택할 수 있고 기존 선택을 유지합니다. |
| 0.3.9 | 개인 Zed의 `threads.db`를 선택해 읽기 전용으로 가져옵니다. Ned 대화를 먼저 백업하고 중복과 충돌을 구분해 병합합니다. |
| 0.3.9 | Zed Agent 프로필의 필수 `name`과 모델 capability를 보완하고, 자체 모델 중계의 일반 HTTP·프록시 요청 처리를 수정했습니다. |
| 0.3.9 | Git 패널의 **Trust Directory** 동작에 번들 Git과 편집기가 감시하는 Ned 전용 설정 파일을 연결했습니다. 사용자가 선택한 저장소 경로 단위로 Git 신뢰를 저장합니다. |
| 0.3.9 | EGM 설계·검토 7종과 읽기 전용 Goldfish를 추가했습니다. 기본 스킬은 74종입니다. |
| 0.3.10 | Ned Agent가 승인 정책을 따라 CMD·PowerShell 명령을 실행하고, 터미널 **+** 메뉴에서 두 셸 중 하나를 고릅니다. Studio의 화면 준비 판정과 진단·재시도를 수정했습니다. |
| 0.3.10 | OpenViking 기본 스킬 등록·재확인과 신규 개인 공통 지식 `.ovpack` 가져오기를 제거했습니다. 기본 스킬 74종은 로컬에서 사용하고, 기존 지식은 유지합니다. 사용자가 직접 만든 글로벌 스킬은 `%APPDATA%\Ned\skills`에 보존됩니다. |
| 배포·문서 | 설치 EXE·반입용 TGZ와 대응 소스, 라이선스, 체크섬, 설치 파일 감사 및 실행 검증 자료를 제공합니다. |

Ned와 개인 Zed를 종료한 뒤 0.3.10 TGZ를 새 폴더에 풀고 EXE를 실행합니다. 기존 설정·대화·
편집기 배치·지식·사용자 수정 스킬이 유지됩니다. 구버전 지식 이관이 필요한 경우 원본을
보존하고 상태 메뉴에 결과를 표시합니다. 개인 Zed 원본 대화는 별도의 가져오기 메뉴에서 선택합니다.
