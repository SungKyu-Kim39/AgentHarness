# Ned 0.4.0 rebuild5 변경 사항

rebuild4를 기준으로 교차 검토한 수정 사항을 반영했습니다. 제품 버전은 0.4.0입니다.

- 설치기는 Ned가 배포한 최상위 항목만 업데이트합니다. 별도로 보관한 최상위 파일은 그대로 두며, 예전 설치 백업에 들어간 개인 파일도 복원합니다. 같은 이름의 개인 파일이 두 곳에 있으면 모두 보존하고 설치를 중단합니다.
- REA 도구는 대화에서 선택한 모드로 제어합니다. REA 모드에서 키워드 없이 분석할 수 있습니다. Plan·Build에서 분석이 필요하면 REA 모드로 전환합니다. 도구 호출 중 프로젝트 조회 결과가 모드를 되돌리는 문제를 수정했습니다.
- 다중 파일 편집 직후 종료되면 디스크 파일의 해시와 저널·스냅샷을 비교해 실제 적용된 파일을 찾습니다. 중단 기록을 조회하고 복구를 요청할 수 있습니다. 이후 편집이나 미저장 버퍼가 감지되면 해당 복구를 보류합니다.
- 일괄 치환·worktree 반영·체크포인트 복원·명세 초기화는 쓰기 대상을 한꺼번에 예약합니다. 공유 worker가 이미 예약한 파일과 겹치면 일괄 반영을 중단합니다.
- OpenViking이 재시작해 기억 추출 작업 번호를 잃으면 아카이브 번호로 상태를 계속 확인합니다. 실패가 확인된 아카이브는 체크섬을 확인해 한 번 재시도하며, 취소된 작업은 그대로 둡니다.
- 대화 요약으로 이전 요청이 모델 입력에서 빠져도, 승인된 같은 대화의 이어가기에서 모델과 호스트가 공통으로 원래 요청을 참조해 전문 도구를 선택합니다.
- 정적 프리뷰에서 하위 폴더의 상대 경로를 바로잡고, 시작 승인 대기 중인 프리뷰를 포함해 동시에 두 개까지만 허용합니다.
