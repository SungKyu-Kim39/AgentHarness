# Ned 0.4.2 rebuild3

Ned Agent의 `/` 목록을 기본 명령, 스킬, 사용자 MCP 섹션으로 나눴습니다. 이 설치본에는 0.4.2 rebuild2의 로컬 MCP 등록 수정도 포함됩니다.

[변경 사항](https://github.com/SungKyu-Kim39/AgentHarness/blob/v0.4.2-rebuild3/docs/changes-0.4.2-rebuild3.md) · [슬래시 명령 사용법](https://github.com/SungKyu-Kim39/AgentHarness/blob/v0.4.2-rebuild3/docs/extension-guide.md)

설치 파일 65,745개를 준비본과 대조했습니다. Windows Server에서 새 설치, 0.4.2-rebuild2 업데이트와 사용자 글로벌 스킬 보존을 확인했고 설치본 대상 검사 69건이 통과했습니다. 직원 PC의 Windows 10·11 GUI와 실제 사내 모델 검증은 남아 있어 사전 릴리스로 제공합니다.
