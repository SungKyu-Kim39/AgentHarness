# Ned 0.4.3

0.4.2 rebuild3의 검증을 거쳐 배포하는 Windows x64 정식 릴리스입니다. Ned Agent의 `/` 메뉴에서 기본 명령, 스킬, 사용자 MCP를 구분해 찾을 수 있습니다. 사내 MCP와 직접 등록한 로컬 주소를 연결해 필요한 도구를 한 요청에 사용할 수 있습니다.

사내망 반입 시 TGZ를 새 폴더에 푼 뒤 설치 EXE를 실행합니다. 업데이트하려면 Ned와 개인 Zed를 종료하고 기존 Ned 설치 경로를 선택하세요.

[변경 사항](https://github.com/SungKyu-Kim39/AgentHarness/blob/v0.4.3/docs/changes-0.4.3.md) · [폐쇄망 설치 안내](https://github.com/SungKyu-Kim39/AgentHarness/blob/v0.4.3/docs/offline-setup.md)

설치 파일 65,748개를 준비본과 대조했습니다. Windows Server에서 새 설치, 0.4.2-rebuild3 업데이트와 사용자 글로벌 스킬 보존을 확인했고 설치본 대상 검사 71건이 통과했습니다.
