# Ned 0.4.3 검증

0.4.2 rebuild3에서 Windows 설치본 검사 69건을 모두 통과했습니다. 설치된 Ned ACP가 기본 명령, 글로벌·프로젝트 스킬, 활성 사용자 MCP에 각각 올바른 범주를 제공하고, MCP를 끄면 목록에서 제거하는지 확인했습니다. 새 설치와 rebuild2에서의 업데이트를 모두 검사했습니다. [rebuild3 Windows 실행 기록](https://github.com/SungKyu-Kim39/AgentHarness/actions/runs/45940091960)

0.4.3은 제품 버전이 표시되는 편집기와 설치 파일을 새로 만듭니다. 지식·스킬·사용자 MCP 등록의 보존, 새 설치, rebuild3에서의 제자리 업데이트, 로컬 HTTPS 연결 확인과 슬래시 선택을 Windows Server 2022에서 검사합니다. 직원 PC의 Windows 10·11에서 슬래시 팝업을 직접 띄우는 확인과 실제 사내 서버 연결은 현장 확인 범위입니다.
