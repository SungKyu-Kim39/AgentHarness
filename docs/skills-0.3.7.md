## 자동 적용

스킬 이름을 몰라도 “실행하면 오류가 난다”, “이 화면의 간격을 다듬어 달라”, “이 글의 번역투를 고쳐 달라”처럼 요청하면 됩니다. 호스트는 현재 요청, 최근 대화, 관련 도구 사용 내역을 살펴 최대 3개의 스킬을 후보로 고릅니다. 파일 해시를 확인한 지침을 모델 요청에 넣고, 모델이 프로젝트 조사 결과와 사용자 결정을 함께 고려해 적용 여부를 판단합니다. 작업 범위가 달라지면 스킬도 다시 선택합니다. 후보 선정은 규칙에 따른 추정이므로, 실제 작업에서 적합한지 확인하는 과정이 필요합니다.

스킬 선택은 기존 모델 요청 안에서 처리하며 별도의 분류 모델을 호출하지 않습니다. 파일 수정·명령 실행·데스크톱 조작에는 사용자가 선택한 ask/edits/full 권한 모드를 그대로 적용합니다. 원하는 스킬의 이름을 직접 지정하거나, 해당 요청에서 “스킬 사용하지 마”라고 말할 수도 있습니다. 긴 참조 문서는 `read_skill`의 `offset`으로 나누어 읽습니다.

## 실행 기능의 범위

스킬은 작업 방법을 설명하는 문서입니다. 게임 스킬을 쓰려면 프로젝트에 필요한 엔진과 자산이 있어야 하며, 이미지·영상 생성기는 별도로 필요합니다. 브라우저 조작이나 명령 실행도 호스트가 지원하는 도구 범위 안에서 수행합니다.

Modern Web Guidance는 AI 모델 다운로드 가이드 5개를 제외한 웹 문서 204개와 로컬 참조 색인을 제공합니다. 원본의 온라인 CLI, 자동 업데이트, 통계 전송 기능은 포함하지 않습니다. 한국어 윤문 스킬은 원문의 사실·수치·장르를 유지하면서 문장을 다듬습니다. 원본에 있는 별도 Python 점수 검증기와 병렬 모델 실행 절차는 사용하지 않습니다.

OpenViking을 설정해 실행하면 새 기본 스킬도 등록됩니다. 이때 파일 무결성을 확인하고, 내용이 다른 기존 사용자 사본은 보존합니다. 모델에 지침을 전달할 때는 설치된 로컬 문서를 읽으므로 스킬 등록이나 임베딩 응답을 기다릴 필요가 없습니다. 개인 대화는 자동 업로드하지 않습니다.

호스트는 설정된 context/output 한도와 요청 크기로 남은 문맥 공간을 계산합니다. 여유가 부족하면 스킬 본문을 추가하는 대신 엔진의 기본 선택 지침과 `read_skill`을 사용합니다. 대화 압축용 체크포인트 요청과 `tool_choice=none` 답변 재출력에는 윤문·개발 지침을 추가하지 않습니다.
