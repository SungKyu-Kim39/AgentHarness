## 자동 적용

스킬 이름 없이 “실행하면 오류가 난다”, “이 화면의 간격을 다듬어 달라”, “이 글의 번역투를 고쳐 달라”처럼 요청할 수 있다. 호스트가 현재 요청·최근 사용자 문맥·관련 도구 활동을 이용해 최대 3개 후보의 해시 검증된 지침을 같은 모델 요청에 함께 제공한다. 답변 모델은 실제 목적·프로젝트 조사·사용자 결정을 바탕으로 관련성을 다시 판단하고 다른 스킬·참조를 선택할 수 있다. 후보 점수는 휴리스틱이며 최적 선택이나 실제 도구 실행 성공을 보장하지 않는다. 작업 범위가 바뀌면 다시 선택한다.

선택에는 별도 승인이나 모델 호출을 추가하지 않는다. 읽기 지침을 불러왔다고 파일 수정·명령·데스크톱 권한이 생기지 않으며 기존 ask/edits/full 모드를 따른다. 스킬을 적용하지 않으려면 해당 요청에서 “스킬 사용하지 마”라고 명시할 수 있다. 이름을 직접 지정하는 방식도 지원한다. 긴 참조는 read_skill의 offset으로 이어 읽는다.

## 실행 기능의 범위

게임 스킬은 엔진·이미지 생성기·영상 제작기를 설치하지 않는다. Modern Web Guidance는 선별 로컬 문서이며 원본 온라인 CLI·자동 업데이트·통계 전송을 포함하지 않는다. 한국어 윤문은 원문의 사실·수치·장르를 보존하며, 원본의 별도 Python 점수 검증기나 병렬 모델을 실행했다고 주장하지 않는다. 현재 호스트가 제공하지 않는 브라우저 상호작용·임의 셸·게임 엔진 실행은 스킬 추가만으로 가능해지지 않는다.

OpenViking이 설정되어 실행 중이면 새 기본 스킬도 기존 등록·무결성·충돌 보존 절차로 등록한다. 지침의 자동 적용은 OpenViking의 스킬 등록 완료나 임베딩 응답을 기다리지 않고 설치 리소스의 검증된 문서를 사용한다. 개인 대화는 자동 업로드하지 않는다.

모델의 설정된 context/output 한도와 요청 크기로 여유를 보수적으로 계산한다. 여유가 부족하면 추가 본문을 넣지 않고 엔진 안에서 계산되는 기본 선택 지침과 read_skill을 사용한다. 압축 체크포인트 요청과 tool_choice=none 재출력에는 윤문·개발 지침을 추가하지 않는다. Modern Web Guidance는 AI 모델 다운로드 가이드 5개를 제외한 고정 웹 문서 204개와 로컬 참조 색인을 제공한다.
