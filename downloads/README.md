[0.2.1 폐쇄망 반입 TGZ — EXE·설정 예제·소스·라이선스 포함](https://github.com/SungKyu-Kim39/AgentHarness/raw/refs/heads/work/downloads/L-Vibe-0.2.1-windows-x64.tgz)

파일은 Git LFS로 저장합니다. GitHub에서 다운로드할 때 Git LFS 설치는 필요하지 않습니다. 소스를 clone하여 바이너리도 받으려면 Git LFS가 필요합니다.

0.2.1은 기본 스킬 34개를 포함하며, 임베딩 JSON 설정 후 최초 실행에서 OpenViking skills에 자동 등록합니다. 변경 없는 재실행은 다시 색인하지 않고 사용자 편집본은 보존합니다. 알림 영역의 **OpenViking 기본 스킬 등록 상태**에서 완료 수와 오류를 볼 수 있습니다.

Windows 실환경 수용 검증 전 후보입니다. Serena/clangd, 명령 실행 및 새 Desktop의 재출력 등은 후속 구현입니다. [0.2.1 검증 보고서](../docs/validation-0.2.1.md)와 [스킬·MCP 조사](../docs/offline-extensions-research.md)를 확인하세요.

이전 0.2.0 EXE/TGZ는 같은 폴더에 유지합니다. 해당 이전 설치본의 기본 스킬은 18개이며 자동 등록 기능은 없습니다.

work 브랜치의 **0.2.2 소스**에는 MCP 6종을 연결했지만 새 EXE/TGZ는 아직 발행하지 않았습니다. 위 0.2.1 파일에는 새 MCP가 없습니다. [진행 상태와 차단 사유](../docs/mcp-validation.md)를 확인하세요.
